# Retail Sales Analytics Dashboard | 2025

## Project Overview
An interactive Retail Sales Analytics Dashboard developed using Tableau to analyze retail business performance.

## Features
- Revenue KPI
- Profit KPI
- Profit Margin KPI
- Monthly Sales Trend Analysis
- Department-wise Sales Performance
- Interactive Region Filter

## Technologies Used
- Tableau
- Data Analytics
- Data Visualization
- CSV Dataset

## Dataset
The project uses a retail sales dataset containing sales, profit, cost, department, product, customer, and region information.

## Project Objectives
To analyze retail sales performance, identify department-wise contributions, monitor monthly sales trends, and provide interactive regional analysis.
